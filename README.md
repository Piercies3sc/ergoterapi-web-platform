# Ergoterapi Bilgilendirme & Egzersiz Platformu (Multi-Page Web Platform)

Ergoterapi egzersizlerini, rehabilitasyon branşlarını ve bilgilendirici medya içeriklerini son kullanıcıya ulaştıran çok sayfalı, responsive ve performans odaklı web platformu.

## 🚀 Öne Çıkan Özellikler
- **Python Şablon Otomasyonu:** Ortak Navbar, Footer, stil ve betik enjeksiyonlarını dinamik yöneten Python build/update scripti.
- **İki Dilli Mimari (i18n):** Türkçe ve İngilizce sayfalar arasında dinamik yönlendirme ve ayrıştırılmış şablonlar.
- **Dinamik Arama & Filtreleme:** Vanilla JavaScript ile çalışma alanları üzerinde anlık metin tabanlı arama deneyimi.
- **Performans & Medya Optimizasyonu:** `loading="lazy"` entegrasyonu ve sayfayı ağırlaştırmayan CSS-gradient kapaklı video modal (popup) oynatıcı mimarisi.
- **Modüler Yapı:** Tailwind CSS konfigürasyonu ve harici `assets/` mimarisiyle temiz kod ayrımı.

## 🛠️ Teknolojiler
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Tailwind CSS
- **Otomasyon / Araçlar:** Python 3 (Template & Content Injection)
- **Deployment:** Netlify
